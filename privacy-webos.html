BLiZ TV — webOS Privacy Notice

Updated 18 October 2026 · Applies to the BLiZ TV webOS media player and its optional device and phone setup services.

BLiZ TV is a media player for sources supplied by the user or assigned by the user's administrator. The player does not include a television subscription or a channel catalogue.

Device and activation information

The app creates random installation identifiers, including a MAC-style identifier. This is not the network hardware MAC address. The activation service receives an activation code and installation identifier to validate access. The device setup service receives the installation MAC-style identifier, its device authentication proof, app version and connection timestamps so it can deliver that device's assigned source. Device authentication keys are stored as hashes on the server.

Sources and provider information

Manually entered M3U and Xtream source addresses and passwords are used in app memory to contact the selected provider. They are not saved locally as a reusable source profile by this webOS app. Sources assigned through the optional administrator panel are stored encrypted in Supabase and delivered to the corresponding authenticated installation. A playlist URL may itself contain provider login details. The chosen provider, artwork host and EPG host receive the requests needed for playback, artwork and programme information, including the connecting device's IP address. Unencrypted HTTP provider addresses do not protect network traffic; HTTPS should be used where the provider supports it.

Optional phone QR setup

The phone setup page encrypts source details before transferring them through the pairing service. Pairing links last five minutes and permit one submission. The encryption key is carried in the link fragment and is not sent to the pairing database. Delivered encrypted payloads are cleared after collection. Expired pairing records are removed when a later pairing is created or the expired record is accessed.

Country ordering

In automatic country mode the app contacts country.is to obtain the country of the internet connection. That service receives the connection's IP address. The app caches only the country code and lookup time for up to 24 hours. The country can be selected manually in More; a manual selection prevents further automatic lookups while selected. A VPN may change the detected country.

Local preferences and playback position

The app stores language, favourites, country preference, activation information, installation credentials and a salted PIN hash in the app's local storage. It can retain up to 100 recent movie or episode playback positions, identified by media metadata, without storing their stream URLs in the playback history. Clearing the app's data removes these local records and creates a new installation identity on the next start.

Administration and retention

The optional administrator panel uses Supabase email and password authentication. Its session is kept in the browser session storage; the panel does not save the entered password. Server-side device assignments and activation records remain until removed or changed by the operator. Pausing or expiring an assignment stops delivery of that source. Contact support to request removal of a server-side device assignment or activation record. No advertising or behavioural analytics SDK is included in this webOS player.
